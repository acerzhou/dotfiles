Operating model

  • brew/Brewfile is the default package baseline.
  • Ollama provides local language-model serving from the default toolset.
  • PROFILE=personal adds packages; it never changes configuration.
  • Configuration is linked into the home directory with backup and restore support.
  • Hammerspoon remains an independent install path with domain-owned documentation.
  • Git identity and shell overrides live only in untracked local files.
